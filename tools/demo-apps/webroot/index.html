Phoenix-RTOS on the Raspberry Pi 4

This page was fetched over TCP/IP by Dillo, running on a Raspberry Pi 4 under Phoenix-RTOS, and rendered by an X server using the glamor GPU-accelerated driver on the Broadcom V3D 4.2 GPU.

What is running underneath

  • Phoenix-RTOS kernel on BCM2711 / Cortex-A72, 4-core SMP
  • Root filesystem mounted over NFS on the on-board Gigabit Ethernet
  • lwIP TCP/IP stack, driving this HTTP request
  • X11 with Window Maker, accelerated through Mesa on V3D

Also ported

CPython 3.14, SQLite, Lua, jq, Redis, GNU coreutils, bash — and, for the GPU, QuakeSpasm, Quake II, Quake III Arena, vkQuake (Vulkan via V3DV) and SuperTuxKart.

Served from the development host over the Pi's netboot network.
